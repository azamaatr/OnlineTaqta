# OnlineTaqta — 4.3

Минималистік қазақша онлайн тақта. Сервер немесе жинақтау құралдары қажет емес.

## Жариялау
GitHub репозиторийінің түбіріне `index.html`, `style.css`, `script.js`, `icon.svg` файлдарын салыңыз. GitHub Pages → Deploy from branch → main / root.

**Маңызды:** бұрынғы нұсқадағы `sw.js` файлды репозиторийден алып тастаңыз. Ескі service worker кэші жаңаруды бөгесе, Chrome DevTools → Application → Service Workers → Unregister, Storage → Clear site data, содан кейін Hard reload жасаңыз. Бұл әрекет браузерде сақталған ескі тақталарды жоя алады: алдын ала `.taqta` көшірмесін сақтаңыз.

## Құралдар
Қалам, өшіргіш, таңдау, жылжыту, сызық, көрсеткі, тіктөртбұрыш, шеңбер, мәтін, сурет. Undo/Redo, масштабтау, тор/нүкте/ақ/қара фон, бірнеше тақта, автоматты сақтау, PNG және өңделетін `.taqta` экспорт/импорт.

## Шектеулер
Тақталар осы браузердің localStorage жадына сақталады, басқа құрылғыларға синхрондалмайды. Сурет көп болса сақтау көлемі толуы мүмкін. PDF экспорты жоқ; PNG-ті браузер арқылы PDF-ке басып шығаруға болады. Бұл Miro-ның толық көшірмесі емес; бір пайдаланушыға арналған тақта. Қаламның нақты Parblo құрылғысындағы мінез-құлқы бөлек тексерілуі тиіс.

## 4.2 жаңалығы
Жоғарғы панельге «Тазалау» батырмасы қосылды. Растаудан кейін ағымдағы тақтадағы барлық нысанды жояды; Undo арқылы қайтаруға болады. Басқа тақталар өзгермейді.

## 4.3 тексеру және скриншот
«▣ Скриншот» батырмасы PNG/JPG суретті файлдан қосады. Mac-та ⌘⇧4 арқылы скриншот жасап, оны буферге көшіру үшін Control пернесін бірге ұстаңыз (⌘⇧Control+4), одан кейін тақтада ⌘V басыңыз. Сондай-ақ суретті сүйреп әкелуге болады. Бұл батырма экранды өздігінен түсірмейді.

Өшіргіш бұрынғы штрихтың тиген бөлігін пиксельдік қабатта өшіреді, өшіру тарихта сақталады. Тазалау барлық ағымдағы нысандарды растаудан кейін жояды, Undo қайтарады. Автосақтау тақта ауысқанда және бет жабылғанда да орындалады.


## v4.4 өшіргіш курсоры
Өшіргіштің дөңгелек көрсеткіші қалам басылып тұрған кезде де pointermove бойынша жаңарады; pointer capture кезінде қатып қалмайды. Курсор тақтадан шыққанда жасырылады, қалыңдық пен масштаб өзгергенде өлшемі жаңарады. CSS hidden күйі сақталады.
